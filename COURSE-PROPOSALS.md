# Rock Rich Course Proposals

These proposals turn Jason's ~189 YouTube videos into a set of tight, finishable Kajabi micro-courses for the Rock Rich community. The guiding philosophy: **not every video is a lesson.** Only videos that contain one actionable system a viewer could implement this week ("lesson" actionability — system/howto/financial) became lessons. Pure vlog, story, viral, and sponsored-review content ("asset") is kept out of the courses and listed separately as marketing/story material.

The catalog is built around the funnel: a **free Greenhouse activation mini-course** ("Rock Rich Starting System") plus a free decision/reality-check course at top-of-funnel, then a slate of focused **Garden ($19/mo)** paid micro-courses, each scoped to a single self-contained system so completion (not just enrollment) is achievable. Three clusters are flagged as **challenge-validation candidates** — self-contained systems with 5-7 strong lessons that can be tested as paid 14-day challenges before committing to a full drip course.

**9 courses proposed. 60 lessons placed. The rest are marketing/story assets.**

## How to Build These in Kajabi

The **Kajabi Public API is read-only for courses** — you cannot create products, outlines, or lessons through it. These courses must be **built by hand in the Kajabi admin** (Products → Course → add Categories as modules, Lessons within each). Recommended workflow:

1. Build the **free Rock Rich Starting System** first — it is the Greenhouse activation magic-moment. Set it as a free offer/product so any logged-in free member can enroll.
2. Build the three **challenge candidates** (Buy Land Broke, DIY Solar, Systems-First) next, but consider running each as a **paid 14-day challenge** before committing to the full drip course, to validate demand cheaply.
3. For each lesson, embed the YouTube video by `youtube_id` and use the `why` line (in `data/course-proposals.json`) as the lesson description / "what you'll get" note.
4. **Full transcripts for every video are in `data/course-corpus.json`** — use them to write lesson summaries, worksheets, action steps, and challenge prompts without re-watching.
5. Watch the known Kajabi MCP quirks (per CLAUDE.md): `create_post`/`create_announcement` return "Unexpected response shape" even on success — never retry; verify in admin first. Badge-on-completion is buggy; award completion badges manually.

Machine-readable version: `data/course-proposals.json`.
